관리자는 전체 사이트를 조회합니다. 일반 사용자는 회원가입 시 정한 사이트 ID와 아래 형식의 센서 값을 자기 서버에 넣으면 중앙 대시보드로 로그가 전송됩니다.
중요: SENSOR_TOKEN 에는 설정 화면에 표시된 본인 sensor_… 값을 넣으세요. 관리자(admin) 토큰이면 프록시의 SITE_ID 라벨과 함께 어떤 사이트로든 기록되며, 일반 사용자 토큰은 회원가입한 사이트 ID 와 반드시 일치해야 ingest 가 성공합니다.
원격 PC·다른 장비에서만 프록시를 돌릴 때: 그 장비 안의 waf_auth.sqlite3 토큰은 이 중앙(8080)과 무관합니다. 반드시 이 대시보드 설정 화면에 나온 sensor_… 값을 원격 장비의 .env SENSOR_TOKEN= 에 그대로 복사해야 /__proxy/health 의 ingest 가 403 없이 들어오고 접속자·프록시 로그에 쌓입니다.

CENTRAL_DASHBOARD_URL={{ central_dashboard_url }}
SITE_ID=회원가입한-사이트-ID
SENSOR_TOKEN=해당-계정-센서-토큰
UPSTREAM_URL=http://실제웹서버:포트
