# 10. AI 2차 탐지 완전구현 설계

## 1. 문서 목적

이 문서는 기존 `ai_second_pass.py` 기반 AI 2차 탐지 기능을 졸업작품 발표와 실제 데모에 사용할 수 있는 수준으로 완성하기 위한 설계 문서이다.

## 2. 현재 상태 요약

| 번호 | 항목 | 현재 상태 | 보완 필요 |
|---|---|---|---|
| 2-1 | AI 호출 | Ollama `/api/generate` 호출 구현 | 상태 진단, 실패 원인 기록 필요 |
| 2-2 | 실행 조건 | `suspicious` 또는 `always` 모드 구현 | 호출 사유를 로그에 남길 필요 |
| 2-3 | 민감정보 보호 | 일부 헤더와 필드 마스킹 구현 | 마스킹 테스트와 문서화 강화 필요 |
| 2-4 | 차단 연동 | `AI-SECOND-PASS` Finding으로 차단 가능 | 대시보드 표시, 통계 분리 필요 |
| 2-5 | 테스트 | 기본 판단/파싱/차단 테스트 존재 | 실패, 타임아웃, 민감정보 마스킹, 상태 API 테스트 필요 |
