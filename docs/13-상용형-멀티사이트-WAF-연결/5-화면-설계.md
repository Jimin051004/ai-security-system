# 13-5. 화면 설계

## 1. 화면 목표

관리자가 실제 상용 WAF처럼 사이트를 등록하고, 연결 상태와 정책을 한 화면에서 조정할 수 있게 한다.

## 2. 신규 화면 목록

| 번호 | 화면 | 경로 | 목적 |
|---|---|---|---|
| 2-1 | 사이트 관리 | `/__waf/dashboard/sites` | 등록된 사이트 목록과 상태 |
| 2-2 | 사이트 등록 모달 | 동일 화면 내부 | 도메인/origin 등록 |
| 2-3 | 사이트 상세 | `/__waf/dashboard/sites/{site_id}` 또는 SPA 섹션 | 정책/룰/예외/IP 관리 |
| 2-4 | 연결 가이드 | 사이트 상세 내부 | DNS/TLS/Caddy 설정 안내 |
| 2-5 | 운영 이벤트 | 기존 탐지 화면 확장 | 사이트별 탐지/차단 이벤트 |

## 3. 사이트 관리 화면

## 3-1. 주요 정보

| 항목 | 설명 |
|---|---|
| 사이트 이름 | 사람이 읽기 쉬운 이름 |
| 도메인 | 보호 도메인 |
| Origin | 원본 서버 URL |
| 모드 | 탐지/차단/비활성 |
| TLS | 외부 Caddy/Nginx 구성 상태 |
| 최근 요청 | 마지막 요청 시각 |
| 차단율 | 최근 로그 기준 차단 비율 |

## 3-2. 카드/테이블 구성

```text
사이트 관리
------------------------------------------------
[+ 사이트 추가]

사이트        도메인              Origin              모드      상태
쇼핑몰        shop.example.com     127.0.0.1:3001      차단      active
관리자        admin.example.com    127.0.0.1:3002      탐지      active
```

## 4. 사이트 등록 모달

## 4-1. 입력 필드

| 번호 | 필드 | 검증 |
|---|---|---|
| 4-1 | 사이트 ID | 영문/숫자/하이픈/밑줄 |
| 4-2 | 표시 이름 | 1~80자 |
| 4-3 | 보호 도메인 | hostname 형식 |
| 4-4 | origin URL | `http://` 또는 `https://` |
| 4-5 | 운영 모드 | detect/block/disabled |
| 4-6 | AI Second Pass | toggle |

## 4-2. 사용 흐름

```text
1. 관리자가 사이트 추가 클릭
2. 도메인과 origin 입력
3. 저장 클릭
4. 서버가 origin URL과 domain 검증
5. 성공 시 사이트 목록에 추가
6. 연결 가이드 표시
```

## 5. 사이트 상세 화면

## 5-1. 상단 요약

| 항목 | 표시 |
|---|---|
| 사이트 이름 | `쇼핑몰` |
| 도메인 | `shop.example.com` |
| Origin | `http://127.0.0.1:3001` |
| 현재 모드 | `차단 모드` |
| 최근 차단 | 최근 24시간 기준 |

## 5-2. 탭 구성

| 번호 | 탭 | 기능 |
|---|---|---|
| 5-2-1 | 개요 | KPI, 최근 위협, 연결 상태 |
| 5-2-2 | 정책 | 탐지/차단/비활성, 최소 심각도, AI 사용 |
| 5-2-3 | 룰 | OWASP 룰별 ON/OFF |
| 5-2-4 | 예외 | 예외 경로 추가/삭제 |
| 5-2-5 | IP 정책 | IP 허용/차단 |
| 5-2-6 | 연결 | DNS/TLS/Caddy 설정 안내 |
| 5-2-7 | 감사 로그 | 정책 변경 이력 |

## 6. 정책 화면

## 6-1. 컨트롤

| 컨트롤 | UI |
|---|---|
| 운영 모드 | segmented control: `탐지`, `차단`, `비활성` |
| 최소 심각도 | select 또는 segmented control |
| AI Second Pass | toggle |
| AI 차단 신뢰도 | slider 또는 number input |
| 장애 모드 | select: `fail-open`, `fail-closed` |

## 6-2. 정책 저장 UX

정책 변경 시 즉시 저장하지 않고, 저장 버튼으로 반영한다.

저장 전에는 변경 요약을 보여준다.

```text
변경 예정
- 운영 모드: 탐지 -> 차단
- AI Second Pass: 꺼짐 -> 켜짐
```

## 7. 룰 화면

## 7-1. 표시 항목

| 항목 | 설명 |
|---|---|
| OWASP 분류 | A03, A05 등 |
| 룰 ID | 내부 룰 ID |
| 설명 | 룰 설명 |
| 활성 여부 | toggle |
| 심각도 override | 선택값 |
| 최근 매칭 수 | 통계 |

## 8. 예외 경로 화면

## 8-1. 예외 추가 폼

```text
Path pattern: /health
Method: GET
Rule: 전체 또는 특정 rule_id
Reason: 헬스 체크 오탐 방지
```

## 8-2. 주의 표시

예외는 공격 탐지를 우회시킬 수 있으므로, 사유 입력을 필수로 한다.

## 9. 연결 가이드 화면

## 9-1. DNS 안내

```text
도메인: shop.example.com
권장 DNS:
Type: A
Name: shop
Value: <WAF 서버 IP>
```

## 9-2. Caddy 안내

```caddyfile
shop.example.com {
    reverse_proxy 127.0.0.1:8081
}
```

## 9-3. 로컬 시연 안내

```text
/etc/hosts:
127.0.0.1 shop.local.test
127.0.0.1 admin.local.test
```

## 10. 기존 화면 변경

| 화면 | 변경 |
|---|---|
| 대시보드 개요 | 사이트 선택 시 해당 사이트 정책과 origin 상태 표시 |
| 탐지·차단 상세 | `detected`, `blocked`, `policy_mode` 구분 |
| 프록시 로그 | domain, origin, site_id 추가 |
| 설정 | 사용자 관리와 사이트 관리 분리 |
| 사이트 연결 | 기존 워커 설치 방식은 유지하되, 신규 사이트 등록 방식 안내 추가 |
